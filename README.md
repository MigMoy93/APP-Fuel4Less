# ⛽ Fuel4Less

> **Save money on every trip.**

Fuel4Less is an Android application developed in Java that helps drivers find the cheapest fuel stations in Spain using official daily fuel prices, Google Maps, and route optimization.

## ✨ Features

- 🗺️ Interactive Google Maps
- ⛽ Find the cheapest fuel stations in Spain
- 🚗 Discover the best fuel prices along your route
- ⭐ Save your favorite stations
- 🔍 Filter by fuel type and brand
- 🔄 Automatic daily price updates

## 🛠️ Tech Stack

- Java
- Android SDK
- MVVM Architecture
- Google Maps SDK
- SQLite
- Firebase
- Selenium
- GitHub Actions
